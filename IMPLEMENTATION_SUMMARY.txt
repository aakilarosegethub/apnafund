Display confirmation + status

┌────────────────────────────────────────────────────────────────────┐
│ 🗄️ DATABASE SCHEMA                                                 │
└────────────────────────────────────────────────────────────────────┘

Table: campaign_promotions

• id (primary key)
• campaign_id (FK → campaigns)
• meta_campaign_id (Facebook Campaign ID)
• meta_adset_id (Facebook Ad Set ID)
• meta_ad_id (Facebook Ad ID)
• meta_creative_id (Facebook Creative ID)
• status (pending|active|paused|error)
• daily_budget (decimal, USD)
• error_message (text)
• promoted_at (timestamp)
• created_at, updated_at

┌────────────────────────────────────────────────────────────────────┐
│ 🔑 WHERE TO GET META CREDENTIALS                                   │
└────────────────────────────────────────────────────────────────────┘

META_ACCESS_TOKEN:
   → https://developers.facebook.com/tools/explorer/
   → Select app → Generate Token
   → Grant: ads_management, pages_read_engagement

META_AD_ACCOUNT_ID:
   → Facebook Ads Manager → Settings
   → Copy numbers only (remove "act_" prefix)

META_PAGE_ID:
   → Facebook Page → Settings → About
   → Page ID section
