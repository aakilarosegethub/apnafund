🎬 IFRAME FEATURES
═══════════════════════════════════════════════════════════════════════════

YouTube URL Parameters:
   • autoplay=1 - Video automatically play hoga
   • mute=1 - Initially muted (browsers ka requirement)
   • loop=1 - Video repeat hoga
   • playlist={{videoId}} - Loop ke liye required
   • controls=1 - User controls visible
   • modestbranding=1 - YouTube logo minimal
   • rel=0 - Related videos kam show honge

Video Features:

═══════════════════════════════════════════════════════════════════════════
📊 HOW IT WORKS
═══════════════════════════════════════════════════════════════════════════

1. System checks if campaign has youtube_url

2. IF youtube_url EXISTS:
   • Extract video ID from URL
   • Create YouTube iframe with autoplay
   • Show video instead of image
   • User can unmute and control video

3. IF youtube_url EMPTY:
   • Show regular featured image
   • Normal image display

🔗 SUPPORTED YOUTUBE URL FORMATS
═══════════════════════════════════════════════════════════════════════════

✓ https://www.youtube.com/watch?v=VIDEO_ID
✓ https://youtu.be/VIDEO_ID
✓ https://www.youtube.com/embed/VIDEO_ID

Example:
   https://www.youtube.com/watch?v=dQw4w9WgXcQ
   → Extracts: dQw4w9WgXcQ
   → Embeds: https://www.youtube.com/embed/dQw4w9WgXcQ?autoplay=1&...
