┌─────────────────────────────────────────────────────────────────────────┐
│                          CONTROLLER LAYER                               │
└─────────────────────────────────────────────────────────────────────────┘

    CampaignPromotionController
            │
            ├─ promoteCampaign($request, $campaignId)
            │   • Validate request
            │   • Check permissions
            │   • Check campaign approval
            │   • Call Meta API Helper
            │   • Save to database
            │   • Return JSON response
            │
            ├─ pausePromotion($campaignId)
            │   • Find active promotion
            │   • Call Meta API to pause
            │   • Update database
            │   • Return JSON response
            │
            └─ getPromotionStatus($campaignId)
                • Query database
                • Return current status
            │
            ▼

┌─────────────────────────────────────────────────────────────────────────┐
│                          HELPER LAYER                                   │
└─────────────────────────────────────────────────────────────────────────┘

    MetaApiHelper (cURL Functions)
            │
            ├─ makeRequest($endpoint, $params, $method)
            │   • Generic cURL wrapper
            │   • Add access token
            │   • Handle errors
            │   • Return JSON
            │
            ├─ createCampaign($name, $objective, $status)
            │   • POST to /act_{id}/campaigns
            │   • Return campaign_id
            │
            ├─ createAdSet($campaignId, $name, $budget, ...)
            │   • POST to /act_{id}/adsets
            │   • Set targeting, budget, page_id
            │   • Return adset_id
            │
            ├─ createAdCreative($name, $message, $link, ...)
            │   • POST to /act_{id}/adcreatives
            │   • Build object_story_spec
            │   • Return creative_id
            │
            ├─ createAd($name, $adsetId, $creativeId, $status)
            │   • POST to /act_{id}/ads
            │   • Link creative to adset
            │   • Return ad_id
            │
            └─ updateStatus($objectId, $status)
                • POST to /{objectId}
                • Update status (ACTIVE/PAUSED)
            │
            ▼

┌─────────────────────────────────────────────────────────────────────────┐
│                          META API LAYER                                 │
└─────────────────────────────────────────────────────────────────────────┘

    Meta Graph API v19.0
    https://graph.facebook.com/v19.0
            │
            ├─ /act_{id}/campaigns
            │   • Create campaign
            │   • Objective: OUTCOME_TRAFFIC
            │
            ├─ /act_{id}/adsets
            │   • Create ad set
            │   • Daily budget
            │   • Targeting
            │   • Promoted object (page_id)
            │
            ├─ /act_{id}/adcreatives
            │   • Create ad creative
            │   • Link URL
            │   • Message
            │   • CTA: LEARN_MORE
            │
            ├─ /act_{id}/ads
            │   • Create ad
            │   • Link adset + creative
            │   • Status: ACTIVE
            │
            └─ /{object_id}
                • Update status
            │
            ▼

┌─────────────────────────────────────────────────────────────────────────┐

            ├─ meta_campaign_id
            ├─ meta_adset_id
            ├─ meta_ad_id
            ├─ meta_creative_id
            ├─ status (pending|active|paused|error)
            ├─ daily_budget
            ├─ error_message
            ├─ promoted_at
            └─ timestamps
