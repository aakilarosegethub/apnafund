 🗄️ PHASE 2: DATABASE SETUP
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

□ Backup your current database
   Command: mysqldump -u root -p database_name > backup.sql

□ Run the SQL migration (choose one method):

   Method A - Laravel Migration:
   □ Run: php artisan migrate
   
   Method B - Plain SQL:
   □ Run: mysql -u root -p database_name < create_campaign_promotions_table.sql
   
   Method C - phpMyAdmin:
   □ Open phpMyAdmin
   □ Select your database
   □ Click "Import"
   □ Upload create_campaign_promotions_table.sql
   □ Click "Go"

□ Verify table created:
   SELECT * FROM campaign_promotions LIMIT 1;

 🔑 PHASE 3: META API CREDENTIALS
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

□ Create/Login to Facebook Developer Account
   URL: https://developers.facebook.com

□ Create a Facebook App (if you don't have one)
   □ Go to: https://developers.facebook.com/apps/
   □ Click "Create App"
   □ Select "Business" type
   □ Fill in app details

□ Get META_ACCESS_TOKEN
   □ Go to: https://developers.facebook.com/tools/explorer/
   □ Select your app from dropdown
   □ Click "Generate Access Token"
   □ Grant permissions:
      - ads_management
      - pages_read_engagement
      - ads_read
   □ Click "Generate Token"
   □ Copy the token (starts with EAA...)
   
   For production:
   □ Generate Long-Lived Token (60 days)
   □ Or create System User (permanent token)

□ Get META_AD_ACCOUNT_ID
   □ Go to: https://business.facebook.com/adsmanager/
   □ Click Settings (gear icon)
   □ Click "Account Settings"
   □ Copy your Ad Account ID
   □ Remove "act_" prefix (use numbers only)
   Example: act_123456789 → use 123456789

□ Get META_PAGE_ID
   □ Go to your Facebook Page
   □ Click "Settings"
   □ Click "About" in left menu
   □ Copy "Page ID"
   
   Alternative method:
   □ Use Graph API Explorer
   □ Request: GET /me/accounts
   □ Copy the "id" of your page

□ Add these three lines (see env_meta_example.txt for reference):

   META_ACCESS_TOKEN=your_actual_token_here
   META_AD_ACCOUNT_ID=your_actual_id_here
   META_PAGE_ID=your_actual_page_id_here

□ Save the .env file

□ Clear Laravel cache (if using Laravel):

   □ Run: php artisan cache:clear

□ Verify environment variables loaded:
   □ Run: php artisan tinker
   □ Type: env('META_ACCESS_TOKEN')
   □ Should show your token (not null)

Test 1: Access Campaign Edit Page
□ Login as a campaign owner
□ Navigate to: /user/campaign/edit/{campaign-slug}
□ Should see tabs: Basics, Rewards, Story, People, Payment, Boost, FAQ, Updates
□ Click "Boost" tab
□ Should see promotion form

Test 2: Verify Form Elements
□ "Daily Budget" input field visible
□ "Target Countries" dropdown visible
□ "Promote Campaign on Facebook" button visible
□ No JavaScript errors in browser console

Test 3: Check Meta API Connection
□ Create test route (add to routes/web.php):

   Route::get('/test-meta-connection', function() {
       try {
           $result = \App\Helpers\MetaApiHelper::makeRequest(
               '/act_' . env('META_AD_ACCOUNT_ID'),
               [],
               'GET'
           );
           return response()->json(['success' => true, 'data' => $result]);
       } catch (\Exception $e) {
           return response()->json(['error' => $e->getMessage()], 500);
       }
   });

□ Visit: /test-meta-connection in browser
□ Should see JSON response (not error)
□ Remove test route after verification

Test 4: Test Promotion Flow
□ On Boost tab, set budget (e.g., $10)
□ Select target country (e.g., United States)
□ Click "Promote Campaign on Facebook"
□ Loading spinner should appear
□ Wait for response (10-15 seconds)
□ Check for success message
□ Check browser console for any errors

Test 5: Verify in Facebook Ads Manager
□ Go to: https://business.facebook.com/adsmanager/
□ Look for new campaign (name starts with "Boost:")
□ Click on campaign
□ Verify:
   □ Campaign status: Active
   □ Ad Set exists with correct budget
   □ Ad exists and is active
   □ Ad links to your campaign page

Test 6: Test Pause Functionality
□ On Boost tab, click "Pause Promotion"
□ Confirm action
□ Check success message
□ Verify in Facebook Ads Manager (status should be Paused)

□ Run query: SELECT * FROM campaign_promotions;
□ Verify:

   □ meta_campaign_id populated
   □ meta_adset_id populated
   □ meta_ad_id populated

   □ status = 'active' or 'paused'

If you encounter errors, check:

□ Check Laravel logs:
   storage/logs/laravel.log

□ Check browser console for JavaScript errors

□ Common errors and solutions:

   Error: "META_ACCESS_TOKEN is not configured"
   □ Verify .env file has META_ACCESS_TOKEN
   □ Run: php artisan config:cache
   □ Restart server

   Error: "Invalid OAuth 2.0 Access Token"
   □ Token expired - generate new token
   □ Check token has correct permissions
   □ Use long-lived token for production

   Error: "META_AD_ACCOUNT_ID is not configured"
   □ Add to .env file
   □ Verify format (numbers only, no "act_" prefix)
   □ Run: php artisan config:cache

   Error: "Campaign not found" or 403 Forbidden
   □ Verify user owns the campaign
   □ Or user is added as collaborator
   □ Check campaign approval status = 1

   Error: CSRF token mismatch
   □ Verify meta tag in header:
      <meta name="csrf-token" content="{{ csrf_token() }}">
   □ Clear browser cache
   □ Try in incognito mode

   Error: "Only approved campaigns can be promoted"
   □ Set campaign approval = 1 in database:
      UPDATE campaigns SET approval = 1 WHERE id = YOUR_CAMPAIGN_ID;
