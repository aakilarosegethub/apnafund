Responsive Header Demo

This is a standalone responsive header component. On desktop, you'll see the normal header with logo on the left. On mobile (768px and below), it switches to the custom layout with logo on the left, hamburger menu on the right, and search input below the header.

Mobile Layout: Logo (Left) → Empty Space → Hamburger (Right) → Search Input (Below)
